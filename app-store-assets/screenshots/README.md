# App Store 截图交付说明

## iPad Pro 12.9/13 英寸横屏

- 输出目录：`ipad-pro-12-9/`
- 文件格式：PNG
- 单张尺寸：`2732 × 2048 px`
- 页面视口：`1366 × 1024 CSS px`
- 设备像素比：`2`
- 文件数量：10 张
- 适用位置：App Store Connect 的 12.9 英寸或 13 英寸 iPad 横屏截图栏

## 文件顺序

1. `01-home.png`：首页，展示动态艺术与互动艺术两大入口。
2. `02-artwork-library.png`：动态艺术作品档案，展示作品缩略图、背景及物件数量。
3. `03-stage-control.png`：舞台控制页，展示多背景、舞台物件、Logo 水印与图层管理。
4. `04-object-properties.png`：物件属性页，展示移动方式、轨道、速度与目标点设置。
5. `05-background-editor.png`：背景编辑页，展示背景切换、转场、BGM、应用音乐与清除全部 BGM。
6. `06-appearance-settings.png`：出场设定页，展示逐个出场、时间间隔与出场动画。
7. `07-live-preview.png`：本地舞台预览，展示背景、物件、Logo 水印和预览状态。
8. `08-interactive-themes.png`：互动艺术主题选择，展示海洋、森林及建筑主题。
9. `09-mask-editor.png`：互动图片遮罩编辑，展示图片导入、遮罩选择与上传流程。
10. `10-remote-keyboard.png`：键盘控制页，展示场景、设备、传感器、音量与方向控制。

## 重新生成

在根项目开发服务器运行于 `http://127.0.0.1:5173/` 时执行：

```powershell
npm --prefix transition-portal-preview run capture:app-store
```

脚本会使用本机 Edge 打开真实应用页面，注入仅用于截图展示的本地作品数据，逐张检查浏览器错误，并验证 PNG 必须严格为 `2732 × 2048 px`。再次执行会覆盖上述同名文件。
