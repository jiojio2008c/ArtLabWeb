# MagicFloor Portal Transition Preview

这是一个与主工程隔离的转场效果实验，只用于确认视觉方向。当前包含首页进入动态艺术、首页进入互动艺术、文件夹下钻，以及从作品卡片进入控制页的完整演示。

## 启动

```bash
cd transition-portal-preview
npm install
npm run dev
```

打开 `http://localhost:5188/`，按以下路径操作：

1. 点击「动态艺术」，查看首页进入「作品档案」的 2.2 秒数码门户转场。
2. 返回首页并点击「互动艺术」，查看纸幕撕裂、魔幻传送门与四张主题卡发牌展开的约 1.3 秒转场。
3. 点击「我們這一家」，查看轻量级文件夹下钻与面包屑展开。
4. 点击 `gggg` 作品卡片，查看作品进入控制页的转场。
5. 点击控制页「返回」，查看对应方案的反向收拢动画。

左下角的方案切换器提供两种深层转场：

- `A 空间共享`：作品卡片外框共享扩展为 16:9 舞台，强调空间连续性与低眩晕感。
- `B 立体书破框`：作品卡片扩框、纸雕背景剥离、舞台折叠生成，角色以弹性落地方式进入。

转场播放期间方案按钮会暂时锁定，互动艺术演示中会自动隐藏。动态艺术右下角「重播转场」可重新观看首页门户动画；互动艺术右下角「重播魔幻转场」可重新观看纸幕与主题卡入场。

互动艺术页面左下角另有选择项尺寸切换器：

- `目前尺寸`：保留原有四张高卡片布局。
- `緊湊目錄`：使用参考图比例的 `184–224px` 近方形卡片，四张单行居中；切换后可重播转场查看最终落位。

该尺寸比较只存在于测试工程，尚未应用到正式互动艺术页面。

首页两张入口卡目前还提供一版测试用的冷紫液态玻璃视觉：外层为半透明深色玻璃与双层高光边框，图片放在独立发光展示窗中，标题使用白色高对比样式；没有加入参考图中的手指提示、手指容器、尺寸网格或说明文字。该视觉暂时只存在于测试工程，正式首页尚未修改。

## 响应式与可及性

- 以 iPad 横屏比例为主要展示目标，并覆盖 `1194 × 834` 与 `1024 × 768` 视口。
- 竖屏时显示横屏提示，不强行压缩控制页布局。
- 系统启用 `prefers-reduced-motion` 时，自动切换为简化淡入淡出，取消撕裂、推进和 3D 翻折。

## 边界

- 不引用主工程 React 状态、网络、缓存、登录或 iOS 配置。
- 不修改根目录 `src`、`desktop-runtime` 或 `ios`。
- 素材是从主工程复制的只读副本。
- 所有包子、老虎、螃蟹等演示素材均由预览工程内部的矢量组件生成。
- 确认效果后，再按现有页面边界选择性接入主工程，不直接复制预览工程状态管理。
