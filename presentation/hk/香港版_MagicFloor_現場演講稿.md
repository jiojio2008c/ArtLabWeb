# MagicFloor 現場演講大綱（香港版）

> 用途：現場講者的路線提示。只保留演講順序與主題，不包含逐步操作、按鈕位置或功能教學。

## 開場｜由 iPad 到舞台

- MagicFloor 的整體流程：iPad 控制、EXE 顯示、Unity 延伸互動。
- 今日演講順序：作品上台 → 舞台呈現 → Unity 互動遊戲。

## 第一部分｜iPad → EXE：作品上台

### 1. 現場設備與角色

- iPad：創作及舞台控制。
- Windows EXE：舞台播放及投影輸出。
- 投影幕／大螢幕：觀眾看到的現場畫面。

### 2. 作品檔案與同步

- 作品檔案、縮圖及素材的整體關係。
- iPad 與 EXE 顯示同一個作品狀態。

### 3. 舞台內容

- 物件與圖層結構。
- 出場排序、物件動畫及目標位置。
- 舞台背景、轉場及背景音樂。

### 4. 預覽與正式呈現

- 從作品設定銜接到舞台畫面。
- 預覽效果、正式播放及現場收尾。

## 第二部分｜Unity：互動遊戲集合

### 1. Unity 在現場流程中的位置

- 接續 MagicFloor 舞台，承載互動遊戲及題目。
- iPad、EXE 與 Unity 形成一條清晰的現場流程。

### 2. 互動主題與遊戲集合

- 互動主題：魔幻森林、美麗海洋、畫境成真等（按現場版本為準）。
- 遊戲類型：問答、藝術展示、運動、打地鼠、打螃蟹及混合題目。

### 3. 題目示範節奏

- 題目展示。
- 互動進行。
- 完成後銜接下一題或返回集合。

### 4. 舞台與互動切換

- 由舞台呈現轉入 Unity 互動。
- 互動完成後回到待機或下一個示範段落。

### 5. 現場備援與收尾

- 確認畫面、聲音、投影及連線狀態。
- 保留預設備援流程，確保演講可以順利完成。

## 結尾｜一條清晰主線

- iPad 編排 → EXE 舞台 → Unity 互動。
- 一部 iPad 串聯創作、舞台呈現及互動遊戲。
